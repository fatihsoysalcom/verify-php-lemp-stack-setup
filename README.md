# Verify PHP LEMP Stack Setup

This example provides a simple PHP script that outputs detailed information about your PHP installation. It serves as a quick check to verify that PHP, a core component of the LEMP stack, is correctly configured and running on your web server. This is a fundamental step in preparing your environment for a WordPress installation.

## Language

`php`

## How to Run

1. Save the code as `index.php` (or any other `.php` file) in your Nginx web root directory (e.g., `/var/www/html/your_wordpress_site/`).
2. Ensure Nginx and PHP-FPM services are running on your Ubuntu 22.04 server.
3. Access the file through your web browser (e.g., `http://your_domain_or_ip/index.php`).
